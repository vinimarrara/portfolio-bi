# Torre de Controle · Portfólio de BI

Versão de portfólio da Torre de Controle que construí para a operação de uma plataforma de compra de cotas de consórcio: **22 páginas navegáveis com dados 100% simulados**.

**[Abrir o painel →](https://vinimarrara.github.io/portfolio-bi/)**

![Prévia](preview.png)

## Páginas
- **Torre de Controle:** visão executiva, daily, funil de conversão, fechamento e pagamentos, transferências, cancelamentos, pendências, safras e metas
- **Carteira e precificação:** preços (aprovados × descartados, deságio), cotas grandes, perfil de cotas e grupos
- **Relacionamento:** experiência do cliente (NPS/CSAT), atendimentos, Reclame Aqui, régua de comunicação e WhatsApp/Meta API
- **Parcerias:** dashboards de parceria, central de administradoras e assessorias

Filtros de período, administradora, parceiro e modelo no topo; clique nos gráficos para filtrar os outros visuais; "Tabela" mostra os números de cada visual.

## Sobre os dados
Todos os números, nomes de administradoras, parceiros, contratos, grupos e protocolos são fictícios, gerados por simulação no próprio navegador. O original roda em Google Apps Script sobre uma base no BigQuery alimentada por pipelines em Python.
